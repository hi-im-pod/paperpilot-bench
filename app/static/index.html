How to connect an agent

Your agent is a small HTTP server in any language. The bench sends one task at a time:

POST /solve
{"task": {"id": "fp-01", "type": "find_papers",
          "input": {"topic": "..."}},
 "tools_url": "http://127.0.0.1:8765/runs/.../tools"}

→ {"abstain": false,
   "output": {"ranked_ids": ["2302.12173", ...]},
   "trace": {"input_tokens": 0, "cost_usd": 0}}

Call the corpus tools while you work. Each takes the same arguments as tools/corpus_tools.py:

POST {tools_url}/search        {"query": "...", "k": 10}
POST {tools_url}/read          {"paper_id": "...", "section": "Results"}
POST {tools_url}/list_sections {"paper_id": "..."}
POST {tools_url}/get_metadata  {"paper_id": "..."}
→ {"result": ...} or {"error": "..."}

Start from examples/http_agent.py, which does all of this.
